# Graduate Machine Learning Engineer - Sample AI, Chelmsford
Sample AI builds document search products for law firms. The graduate ML engineer will help develop retrieval-augmented generation (RAG) pipelines, fine-tune embedding models, and evaluate search quality using metrics such as NDCG and recall at k.
Required skills: Python, PyTorch, Hugging Face Transformers, and familiarity with vector databases such as FAISS, Chroma or pgvector. Experience deploying models with Docker or on AWS is a plus.
The team works fully on-site in Chelmsford, Essex. Salary: 38,000 GBP plus bonus. Sponsorship is not available.
